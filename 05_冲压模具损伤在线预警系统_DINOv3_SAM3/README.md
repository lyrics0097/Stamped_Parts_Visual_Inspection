## 一、 核心痛点解答：模具磨损与连续冲压件划痕的内在物理/摩擦学机理

针对项目推进中**“不清楚模具磨损与冲压件划痕之间的内在联系原理，难以区分随机磕碰与模具固定损伤”**的核心痛点，本系统结合现场采集的 `CH260LAD+Z` 热镀锌后轮罩照片（特别是微距缺陷图 `637_4.jpg`、`685_4.jpg` 与现场 SOP 作业标准书 `671_4.jpg`）建立了严格的**三阶段摩擦学演化与时空反演数学模型**：

1. **粘着磨损萌生期（Adhesive Galling / Zinc Pickup Nucleation）**：
   - `CH260LAD+Z` 表面覆盖较软的纯锌层（硬度约 $45\sim 60\,\text{HV}$），在 `OP50` 深拉延立壁圆弧区（`Zone A`）与法兰翻边根部（`Zone C`）承受高接触正压力 $\sigma_n$ 与剧烈塑性滑移。
   - 模具凹模圆角或压料圈局部润滑膜破裂时，锌层发生微观冷焊（Cold Welding）并转移粘附在模具表面形成微米级**粘锌积屑瘤（Pickup Lump）**。此时冲压件在对应固定流线坐标 $(u_0, v_0)$ 出现**断续、微弱的浅表擦痕**（滑动窗口重现率 $R_W \in [0.30, 0.60)$）。
2. **加工硬化犁沟扩展期（Work-Hardened Ploughing Growth —— 黄金修模预警窗口）**：
   - 随着冲次 $k$ 累积，模具表面粘附的锌-铁瘤块在反复高压摩擦与氧化作用下发生剧烈加工硬化（硬度飙升至 $400\sim 600\,\text{HV}$ 以上，显著高于后续进入模具的新鲜板料基体），演变为楔形硬质微凸体，对每件经过该模腔位置的板料实施**刚性犁削（Ploughing）**。
   - 表现在连续冲压件上，即出现如现场特写 `637_4.jpg`（立壁竖向平行拉毛，倾角 $89.4^\circ$，最大长度 $24.61\,\text{mm}$，均宽 $0.691\,\text{mm}$）和 `685_4.jpg`（法兰面 $1\sim 5\,\text{cm}$ 密集竖向拉痕，均宽 $0.785\,\text{mm}$）所示的**空间坐标高度锁定、方向严格沿拉深金属流动矢量 $\vec{v}_{\text{flow}}(u,v)$（约 $90^\circ$ 竖向）、长度与深度随冲次单调增长（$\beta_L \ge 0$）**的周期性划痕。此阶段触发**二级预警（班中油石打磨凹模圆角）**，可避免模具彻底拉伤报废。
3. **模具崩刃/严重咬死期（Severe Galling & Die Scoring）**：
   - 硬质积屑瘤进一步长大导致拉深阻力剧增，引发法兰根部起皱（如 `685_4.jpg` 钢尺 $4\sim 5\,\text{cm}$ 处 $35.3\times 14.2\,\text{mm}$ 的起皱变形）甚至拉深立壁暗裂/开裂（SOP 红框重点缺陷）。重现率 $R_W \ge 0.85$，触发**三级停机保护报警**。

### 模具损伤拉痕 vs. 产线随机磕碰划痕的物理判别准则

| 判别维度 | 模具固定损伤（粘模/拉毛/犁沟） | 传送带/机械手/搬运随机磕碰 |
| :--- | :--- | :--- |
| **标准坐标系空间位置 $(u_k, v_k)$** | **高度锁死**（同一模腔坐标重现，$\|\Delta \mathbf{p}\| < \epsilon$） | **空间随机游走**（服从泊松/均匀随机分布） |
| **划痕主方向角 $\theta_k$** | **严格平行于局部冲压流线 $\theta_{\text{flow}}(u,v)$**（立壁/法兰竖向 $90^\circ\pm 8^\circ$） | **方向任意杂乱**（常偏离拉深流线方向，$w_{\text{flow}}(\theta) \ll 1$） |
| **多件重现率 $R_W(u,v)$（窗口 $W=8$）** | **高重现率**（萌生期 $0.30\sim 0.60$，扩展期 $\ge 0.60$，严重期 $\ge 0.85$） | **极低重现率**（单件偶发脉冲，$R_W \le 1/W = 0.125$） |
| **形态演化斜率 $\beta_L$** | **单调不减或正增长**（$\beta_L \ge 0$，长宽随粘锌体积累积而增长） | **无时间相关性**（单次脉冲后立即消失） |

## 三、 快速运行指南（命令行接口）

所有脚本均在本地 `rad_env` 环境（无需云端 GPU 即可在本地极速运行）下验证通过：

```powershell
$env:KMP_DUPLICATE_LIB_OK="TRUE"
$env:PYTHONIOENCODING="utf-8"
$PY = "C:\Users\lyz\anaconda3\envs\rad_env\python.exe"

# 1. 运行模块一：产线视频关键帧提取、节拍测算与工件位姿配准
& $PY step1_prod_line_extractor.py

# 2. 运行模块二：DINOv3 空间锚定记忆库与高反光微弱划痕提取
& $PY step2_scratch_and_memory_bank.py

# 3. 运行模块三：连续冲压件时空关联反演与 100 冲次生命周期评测
& $PY step3_spatiotemporal_warning.py

# 4. 运行模块四：RealSense D455 实机连接验证、生成 HMI 演示视频与 200 轮稳定性压测
& $PY run_d455_hil_verification.py

# 5. 启动主系统实时监控（支持 d455_live / video_replay / hil_benchmark 三种模式）
& $PY stamping_die_warning_system.py --mode d455_live
& $PY stamping_die_warning_system.py --mode video_replay
& $PY stamping_die_warning_system.py --mode hil_benchmark --iters 200
```
