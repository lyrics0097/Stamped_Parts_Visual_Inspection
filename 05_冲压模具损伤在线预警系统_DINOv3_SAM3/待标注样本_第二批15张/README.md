## 一、 工业背景与工件物理机理

- **工程项目**：华域汽车（HASCO）/ SAM 冲焊工厂冲压模具损伤在线预警系统
- **核心冲压件**：上汽大众左/右后轮罩（Left/Right Rear Wheelhouse，零件号 `1PE 810 425 / 1PE 810 426`）
- **冲压工序**：`OP50-RST+SEP`（整形 + 分离工序，深拉延成型关键道次）
- **板料材质**：`CH260LAD+Z` 汽车用热镀锌高强冷轧低合金钢板，公称板厚 $0.7 \pm 0.04\,\text{mm}$
- **模具损伤与拉毛形成物理机理**：
  在高速连续冲压（15~20 冲次/分钟）过程中，板料表面的纯锌镀层在凹模高受力圆角处承受极高接触压应力与剧烈摩擦滑移。由于锌的剪切强度显著低于模具钢基体，局部润滑油膜破裂导致**冷焊转移（Cold Welding / Galling）**，在凹模工作表面聚集形成坚硬的粘锌积屑瘤。积屑瘤作为刚性压头，对后续连续通过的板料表面实施微观犁削（Micro-plowing），形成顺延材料流动方向（约 $90^\circ$ 竖直方向）的线状拉伤与犁沟擦痕。若不及时预警油石修模，拉毛将迅速加剧演变为穿透性裂纹并导致模具硬化层剥落报废。

## 二、 零件特征区域定义（Part Zones）

为实现空间局部自适应检测与坐标系对齐，工件表面划分为三大核心特征区域：

| 区域代码 | 区域名称 (Part Zone) | 几何特征与应力状态 | 典型缺陷分布 | 标注与检测注意事项 |
| :--- | :--- | :--- | :--- | :--- |
| **Zone A** | **深拉延立壁区 (DrawWall)** | 大深度立壁圆弧过渡区，材料剧烈拉延变形与减薄区，正压力最高。 | **竖向拉痕 (scratch)、粘模拉毛 (galling)、犁沟擦伤** | 缺陷主方向严格沿 $90^\circ \pm 8^\circ$ 竖向金属流动线分布；高信噪比区域。 |
| **Zone B** | **顶部平坦区与加强筋 (Flat Top)** | 零件顶部平坦承载面，分布有冲压刚度加强筋与减重槽。 | 一般无拉毛缺陷；主要存在表面轻微滑移浮油。 | **高反光敏感区**：车间条形 LED 灯易在此形成白色镜面反射带，需注意防范过曝误检。 |
| **Zone C** | **底部法兰翻边与切边 (Flange)** | 零件外缘水平翻边带及落料冲孔切边口。 | **法兰拉伤、起皱 (wrinkle)、切边毛刺 (burr) 与微裂纹 (crack)** | 需重点关注法兰根部微起皱波纹，以及切边刃口的锯齿状微观撕裂。 |

## 三、 四大缺陷类别与多边形标注规范（给标注员 黄逸伦 同学）

推荐使用 **LabelMe**（或 AnyLabeling / ISAT）工具进行多边形（Polygon）精准标注。每个标注完成的图片请保存为**同名 `.json` 文件**同目录存入。

### 1. 缺陷类别定义与标签命名

| 类别标签 (Label) | 缺陷中文名称 | 视觉表观特征与物理形态 | 典型分布位置 | 标注精细度要求 |
| :--- | :--- | :--- | :--- | :--- |
| **`scratch`** | 竖向拉痕 / 模具划痕 | 沿板料拉延流动方向（竖直 $90^\circ$ 走向）分布的细长深色/暗色线状条纹，宽约 $0.2 \sim 1.5\,\text{mm}$，平行多道排列。 | Zone A 立壁区、Zone C 法兰根部 | 沿细长条纹外边缘紧致勾勒多边形；条纹中间若有因光照角度微弱断续，**应按连续条纹整体勾勒**（符合物理拉延连续性与 SnakeSAM 特征）。 |
| **`galling`** | 粘锌拉毛 / 擦伤簇 | 凹模粘锌冷焊引发的面状聚集性粗糙划伤带，表面呈密集的羽状、梳齿状或毛刺擦伤簇。 | Zone A 左下圆角高应力区、模具台阶过渡处 | 若多道细小拉毛密集连成一片，可勾勒整个毛糙区域的外包络多边形；若界限明显可分解为单条 `scratch`。 |
| **`wrinkle`** | 起皱 / 应力波纹 | 压边力不足或金属流速不均引发的塑性失稳褶皱，在切向光照下呈现明暗交替的波峰与波谷起伏条带。 | Zone C 法兰过渡区、立壁与法兰交界根部 | 沿起皱波纹产生的凹凸阴影边缘勾勒闭合多边形，覆盖变形影响带。 |
| **`burr`** / **`crack`** | 切边毛刺 / 微裂纹 | 模具刃口磨损导致的剪切断裂带微观毛刺突出（burr），或局部应力集中产生的细微撕裂微裂（crack）。 | Zone C 法兰外切边刃口沿线（如 `01` 号 4K 样本） | 紧贴切边边缘向外凸起的毛刺锐角或暗色微裂缝隙贴边标注。 |

### 2. 标注注意事项与防误检要点
1. **防范镜面反光误标**：工件镀锌表面及冲压防锈油在车间顶棚灯照射下会产生明亮的白色光斑（条形光晕）。请仔细辨识：**反光条带边缘平滑且通常与灯具走向平行，无金属微观犁削凹槽，严禁将镜面高光误标为缺陷**。
2. **区分冲压加强筋与真实划痕**：工件自带的设计圆弧凸台和加强筋轮廓是正常几何结构，其边界过渡平滑自然；真实划痕具有微细、尖锐、带暗黑边缘的特征。
3. **保持 JSON 与图片文件名严格一一对应**：例如针对 `01_4K超清微距_模具信息_6_法兰切边毛刺与微裂特写.jpg`，导出的标注文件必须命名为 `01_4K超清微距_模具信息_6_法兰切边毛刺与微裂特写.json`。
