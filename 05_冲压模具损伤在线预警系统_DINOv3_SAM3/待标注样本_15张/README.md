# 冲压件表面缺陷手工标注样本集（15 张）

本目录存放用于模型评估与真值基准构建的 15 张代表性产线冲压件图像样本：

- **`01` ~ `02`**：冲压件立壁拉毛与法兰边拉痕微距特写（`637_4`、`685_4`）
- **`03` ~ `05`**：第一批产线实拍冲压件样本
- **`06` ~ `08`**：第二批 4K 高清冲压件立壁竖向平行拉毛样本
- **`09` ~ `15`**：经单应性矩阵配准（Registration）拉正后的标准正视角冲压件图像

可使用 LabelMe / ISAT / AnyLabeling 等工具对表面划痕、拉毛及凹坑区域进行多边形或掩码标注。
